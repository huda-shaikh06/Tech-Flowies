# 🩸 BloodBridge — Connecting Lives Through Blood Donation

**Team Name:** Tech Flowies  
**Domain:** Healthcare

## About the Project
BloodBridge is a healthcare web application designed to help people connect with blood donation support. It aims to make it easier for users to find nearby blood banks and access blood-related services.

## Problem Statement
Finding blood donation support quickly can be difficult during emergencies. BloodBridge aims to make this process easier by providing a simple website with useful blood-related information and a map for locating nearby blood banks.

## Key Features
- **Blood Bank Map:** Explore nearby blood bank locations on an interactive map.
- **Simple Interface:** Access the website through an easy-to-use design.
- **Healthcare Support:** Help users find relevant blood donation resources.

## Technology Stack
- **Frontend:** HTML, CSS, JavaScript
- **Map:** OpenTopoMap
- **Deployment:** Vercel
